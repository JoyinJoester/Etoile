# 隐私与数据

Etoile 是独立的 GitHub / GitLab Android 客户端。本说明描述当前源码的实现；第三方服务另有自己的条款与隐私政策。更新日期：2026-10-21。

## 账户与授权

设备会连接 GitHub 或你选择的 GitLab 实例，以完成登录、读取内容和你要求的操作。访问令牌、刷新令牌及待完成 OAuth 的校验数据保存在 Android Keystore 支持的加密偏好存储中。GitHub 与 GitLab 使用独立账户存储。如果构建配置了 GitHub 认证服务，授权交换和刷新请求还会发送至该服务，其服务端处理和留存由对应运营者负责。

Etoile 不直接要求你提供服务密码。浏览器与内嵌登录页面由对应服务提供。Release 构建固定不嵌入 GitHub OAuth Client Secret，浏览器授权需配置已部署的授权服务。Debug 的个人 OAuth App 兼容模式可内嵌 Secret，该值无法在安装包中保密。

## 设备上的数据

应用在私有存储中保存账户资料、设置、本地 Stars 分类、草稿、阅读缓存、所选应用源和下载的软件包。GitHub 响应缓存经过加密；草稿及其他偏好并非全部单独加密。草稿恢复取决于对应页面及 Android 任务生命周期，不是外部备份服务。应用已关闭 Android 应用备份。

移除账户会删除其本地凭据，不会删除你的 GitHub / GitLab 账户，也不等于在服务端撤销全部授权。需要撤销时，请前往对应服务的安全设置。清除应用存储或卸载可移除剩余应用数据和下载；流转至应用存储以外的副本由 Android 和目标安装器管理。

## 网络请求与第三方

GitHub 和你选择的 GitLab 实例会接收使用功能所需的 API 请求。打开应用商店可能从启用的 F-Droid 软件源获取目录；下载软件包会连接对应托管服务；头像和 Markdown 图片可能连接内容中指定的图片主机。这些服务会收到 IP 地址、所请求资源等普通连接信息。外部浏览器页面及安装的应用遵循各自的政策。

当前依赖配置不包含广告或统计分析 SDK，应用不会自动向开发者上传诊断数据。主动反馈问题前，请先从日志和截图中移除令牌、私有仓库内容和个人信息，不要在公开 Issue 中提交凭据。

## 权限

网络和网络状态权限用于 API 与下载。通知权限用于可选的登录代码通知，登录不要求授予该权限。安装软件包权限仅在你选择把下载的软件包交给 Android 系统安装器时使用，系统可能另行要求允许此应用安装软件。已安装版本查询受 Android 软件包可见性限制。

## 联系与变更

源码及公开问题追踪位于 https://github.com/JoyinJoester/Etoile。涉及隐私的问题请勿公开敏感材料，可先向维护者询问私下联系渠道。服务地址、存储方式、权限或第三方依赖变化时，需重新审核本说明。
