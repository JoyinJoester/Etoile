# 当前版本页面优化

基于 2026-10-21 的现有 Compose 页面绘制；入口为 [index.html](index.html)。旧版画布保留为历史资料，本轮不以旧稿决定功能或导航。

## 设计约束

- 首页保留当前七行紧凑工作入口及其顺序。根据用户反馈撤回四格大卡片，手机和宽屏均不使用任务卡片布局。
- 头像列表采用左侧头像、右侧信息左对齐并紧贴头像；仓库、关注者、已关注统计保持横排。
- M3E 使用语义色和 tonal surfaces，减少无意义描边、分隔和整行缩放；已保存的默认风格和主题不变。
- 搜索、筛选、结果保持清楚的阅读顺序；短筛选在空间充足时使用分段控件，长标签和大字号退回可横滚筛选。
- 详情优先显示内容，低频管理放在更多入口。已有二次确认、权限判断、提交锁定、草稿保留和账户隔离继续生效。

| 页面族 | 画布内容 | 本轮原生调整 |
| --- | --- | --- |

| 仓库与阅读 | 仓库入口、更多、代码、README、分支、发行版、附件、成员与管理 | 仓库、提交、发行版、目录、分支、标签统一表面；分支状态下移，Webhook 管理收进行末菜单 |
| 讨论与审查 | Issue、PR、讨论、编辑、审查、合并与元信息 | Issue / PR 及搜索结果行统一；讨论使用共享顶栏，详情编辑收进更多；长评论按需绘制，回复线程和编辑返回保留草稿与阅读位置 |
| 账户与设置 | GitHub 登录、多账户、GitLab OAuth、设置、外观、语言和缩放 | 设置入口合为一组；共享标签和容器适配 M3E，已有登录流程不变 |

| 状态 | 加载、空列表、失败、提交、权限和危险确认 | 共享短反馈缩小无效留白，保留明确重试；安全行为沿用现有实现 |

画布中的示例数据不来自真实账户。辅助入口帧用于说明路径，不代表其全部原生界面在本轮重写。首页“贡献与收藏”续页只用于固定画布表达向下滚动，原生不新增按钮或分页。

## 验证边界

`verification.json` 记录 M3E Canvas 浏览器中的深浅色逐帧检查；`previews/` 为实际画布渲染。截图应在转场完成后获取，不能作为 Android 设备截图或原生性能证明。

原生验证使用 `compileDebugKotlin`、`testDebugUnitTest` 和 `lintDebug`。不生成或安装 APK，不执行真实账号写操作。新增 Robolectric API 34 原生绘制验证，以真实 Compose 组件和本地示例检查布局与点击；快照见 [native-previews](native-previews/)。这些是主机环境中的原生组件绘制，不代表实体设备或实际帧率。主题依赖包含 Java 21 类，单元测试运行器使用 Java 21。

本轮结果：96 个画面的深浅色共 192 次渲染，无元素越界或页面脚本错误；9 条原型跳转检查通过。原生编译通过，111 个测试类、921 项测试全部通过，其中 13 项为原生布局与交互测试；Lint 无错误、139 条警告。分别见 `verification.json`、`interaction-verification.json` 和 `native-verification.json`。

原生交互覆盖首页手机 / 宽屏七行入口及点击顺序、头像文字紧贴头像左对齐、320dp / 1.5 倍字号设置页、讨论打开、长讨论懒加载与回复线程草稿保留、Markdown 标题与表格、GitLab Markdown 文件与详情正文、GitLab 管理及作业重试二次确认、评论 quick actions 确认与失败保留草稿 / 成功关闭编辑器，以及编辑正文和查看日志返回后的列表位置保留。尚未覆盖所有画布帧的原生截图，真实设备转场帧率仍需后续验证。

运行 `node docs/design/m3e-canvas/current/generate.mjs` 可重建八组 JSON、分享链接和门户。画布基于 [M3E Canvas](https://github.com/lnkiai/m3e-canvas) 的公开格式；JSON 每组小于 100 KB。
