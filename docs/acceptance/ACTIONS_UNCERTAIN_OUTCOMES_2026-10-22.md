# Actions 未确认结果验收

## 修改与边界

Run 重跑/取消、Workflow 启停与手动触发在调用网络前同步提交本地操作标记。生产导航从应用依赖注入同一个持久 journal；预览和无依赖的组件测试使用内存实现。状态按数值账号、仓库、操作种类和目标 ID 隔离。同一应用实例拒绝仍在进行的重复调用，即使传入重复确认也不能绕过。

只有当前会话接受的明确成功才清除标记。失败、取消、迟到响应和页面离开保留提示；重新进入、重建 journal 后仍需检查。用户可只读查看最新状态，或明确清除本地警告；这两条路径均不重发写请求。再次执行需要新的确认，取消、字段变化与账号变化使待确认失效。

私有偏好存储只保存账号/仓库作用域的 SHA-256 键、操作种类、目标 ID 和随机尝试 ID，不写入令牌、ref、inputs 或正文。存储不能读取时禁用上述写入；不能提交标记时不发请求。完成阶段清理失败保留警告。该机制不保证服务端幂等，不协调多个 Android 进程，也不代表 Release 或其他全部写入口具有同等保护。

## 实际验证

- 修复前新增的重复 dispatch、run、toggle 三项回归全部失败：`.codex-tmp/acceptance-actions-uncertain-red.log`。
- Journal 单元测试 8 项：持久标记恢复、账号/仓库/种类隔离、活动调用互斥、旧成功不能清除新尝试、提交/清理失败、保存期间取消、会话变化/取消后迟到成功，以及只读检查和本地清除。
- 实际 SharedPreferences / 后台线程测试 1 项：延迟初始化、键值内容、新实例恢复、账号隔离及本地清除。新建存储对象不能代替真正 OS 杀进程验收。
- ViewModel 新增 6 项：三个原始失败回归，以及新 VM 恢复后刷新不重发、显式重试成功清除、多账号隔离与本地确认、存储不可读禁止写入。
- Compose 主机新增 3 项：重复操作先确认、取消不发送，仓库检查与本地清除不写入，以及 ref / inputs / 账号变化使待确认失效。
- 最终定向日志：`.codex-tmp/acceptance-actions-uncertain-targeted.log`。源码完整验证与实际数量统一记录在 [本轮验证](VERIFICATION_2026-10-22.md)。

这些是本地仓库替身、真实偏好存储主机测试和选定生产组件的证据；尚未证明完整 Actions NavHost、真实授权写入或 Android OS 杀进程后的整套行为。
