## 已修复并验证的范围

- Actions/Release 的写回调携带显示账号 ID，入口、排队协程开始及结果回写前核对实时会话；绑定仓库在 IO 构造请求时用存储锁核对活动账号、账号凭据与读取令牌，不选取切号后的替代令牌，同账号正常轮换可继续使用。Workflow 行自身持有账号确认键，Dispatch 页内部按账号/仓库/工作流区分保存字段，生产外层重复账号 key 移除。此结果只覆盖相应操作，不能推断其他写入口、不确定结果状态机或完整 Actions 生产导航均已通过。
- GitHub 11 个资源请求文件的 56 个调用接入 `readGithubResponse`。非 GET/HEAD/OPTIONS 请求使用一次性请求体，不跟随重定向、不自动重试；GET 保留原客户端读取策略。取消覆盖实际 Call 和响应正文读取，保留拦截器、认证、上传超时及正文；上传每次用户明确尝试只打开/关闭一次输入流。代表操作覆盖 POST/PUT/PATCH/DELETE；GraphQL POST 读取也保守使用相同策略。原有 Discussions 专用保护保持。此改动不证明多请求操作原子性，也不替代全部入口的账号绑定或未确认结果状态机。
- 账号隔离扩展到 Actions、Releases、Commits、Issue/PR 列表、Compare、组织、个人仓库、屏蔽列表等保留页面。ViewModel 持续订阅账号，切换时取消请求并清理旧数据、权限；应用迟到结果前复核取消。仓库详情、Webhook Deliveries、MyWork 导航也接入持续订阅。确认状态以数值账号 ID 隔离，屏蔽动作额外绑定确认时的账号和目标用户。
- CreateIssue / CreateRepository / Release 编辑草稿按账号保存，旧账号提交成功不能清空新账号草稿或触发导航。Release 草稿还区分目标，失败保留、成功只清除当前目标；SavedStateHandle 重建后手动打开编辑器可恢复，切号不自动打开。发布/转为草稿先进入整页编辑器，明确保存才提交；写操作检查确认时的账号 ID。首页会话变化已接入现有清理逻辑，退出后清除贡献图。Stars 标签按账号存储，通知刷新、逐项及批量已读的并发回滚回归通过。
- CreatePR / Discussions 持续观察真实会话，保留页切号时取消旧请求、清理私有数据及成功事件；草稿按数值账号 ID 隔离，Discussions 同时按仓库隔离。请求排队后切号、迟到成功及非合作旧请求不能污染当前页或清空原草稿。CreatePR 成功导航只在页面 RESUMED 且实时账号匹配时消费一次；返回可重试被取消的首屏读取。SavedStateHandle 重建和状态消费测试不等同于实际 NavHost / 进程死亡验收。
- Discussion 详情新增保留的 ViewModel；讨论、评论编辑及顶层/楼中楼回复草稿按数值账号、仓库和讨论隔离。实际 IO 核对绑定账号及令牌，GraphQL 不跟随重定向，修改不自动重放，取消贯穿 Call 与正文读取。答案变更需确认；删除确认不恢复，页面作用域使行回收不取消删除，提交期间阻止返回。调用修改前持久化未确认标记，当前有效成功才自动清除；失败、取消和重建后保留提示，重复回复需明确确认，只读刷新及本地“已检查”不写入。整页评论编辑的未输入返回采用最新正文，已输入稿件保留；统计采用服务端新值。
- 会话导航依赖收窄为现有 domain service 接口，生产仍传相同仓库；测试无需创建真实凭据存储。生产 NavGraph、NavHost、条目生命周期与应用过渡参与主机测试；首页、账号选择及登录为占位目的地，会话由测试驱动，不能证明完整应用外壳或真实账号 UI 已通过。
- GitHub 浏览器授权的 pending-store 准备和清理移至 IO，增加准备状态、取消顺序与过期回调保护。真实工作线程阻塞测试证明准备时仍可输入和取消；旧清理完成后才开始下一次授权。回调拒绝重复参数、编码后的重复参数、畸形编码和 code/error 混用，不消耗当前有效授权。
- GitLab 浏览器授权准备/取消改为挂起接口，账号及 pending 存储操作移至 IO；取消立即更新界面，后续准备等待清理完成；旧回调和清理失败仍受取消标记约束。相关存储调度、取消顺序及冷启动回调回归通过。
- GitHub 加密存储延迟初始化，失败可恢复且不清空凭据；恢复、切号、删除及刷新互斥操作在 IO 执行，取消后拒绝持久化迟到结果。GitLab 多页刷新原子替换与列表返回位置回归通过。
- 商店来源、私有详情、Release 缓存和下载状态随账号清理。下载以临时文件进行完整性检查，失败/取消清理，成功后才提交；包解析、已装版本查询及源存储移至 IO，F-Droid 目录合并移至 Default。
- 商店阅读页自定义手势限制累积距离并渐进阻尼，松手后弹簧回位；96dp 触发距离对应约 16dp 可见位移，长拖动仍小于 24dp。回归证明上限、反向立即释放、阻尼及密度缩放。F-Droid 筛选由 ViewModel 在 Default 执行，查询变化取消旧扫描，过时结果不提交；计算期间显示进度、不显示错误的空列表结论，阅读器不会按旧筛选前进。下载进度不重复触发筛选。独立工作线程、阻塞期间可修改查询和取消结果回归通过；超大目录真机耗时仍需测量。
- Release 固定生成空 GitHub OAuth Client Secret，Debug 保留个人 OAuth App 兼容模式。统一源码脚本及所有 Release pre-build 执行约束检查；模拟本机 Secret 不进入生成的 Release 字段，模拟覆盖 Release 为非空值时 pre-build 被拒绝。浏览器登录需部署授权服务，Device Flow / PAT 保留。文档已同步区分 Debug 与 Release，并纠正刷新令牌说明；未读取或输出私人凭据值。
- 原生 About、离线隐私、GPL 全文、字体 OFL、版本/源码/反馈入口的主机测试通过。新增 **222 个 Maven 模块、30 个 Cargo 包**的许可清单、20 份去重发布声明及 Apache/MIT 完整文本，组合进离线第三方声明并验证可读。
