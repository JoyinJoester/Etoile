本轮使用 ADB 操作手机模拟器 `emulator-5554`（AVD `Monica_Issue136_API_32`）。Android 12，x86_64；显示覆盖尺寸 1080×2100、420 dpi，起始系统字体倍率 1.5。Wear 模拟器未操作。

现有安装包是 `takagi.joyin.github.etoile`，versionName 0.1.0 / versionCode 1，targetSdk 34，最后安装时间为 2026-10-21 08:40:52（设备返回值）。本轮没有构建或安装 APK。该版本不能视为当前未提交源码的验收结果。

## 实际操作与证据

启动应用时恢复到旧 GitLab 账号示例页；截图包含 Sample GitLab User，不能据此声称完成真实 GitLab 登录。随后显式打开生产 EtoileActivity，检查未登录主页、进入设置和返回。临时将字体改为 1.0 比较布局，操作后恢复 1.5。

截图和录屏保存在 `app/build/reports/acceptance/emulator-2026-10-22/`，由 ADB screencap / screenrecord 取得；与 Robolectric 主机绘制分开记录。原始录屏在卡顿的系统上采集，不能据其时间轴推断稳定帧率。

## 发现与处理

1. 搜索额度还剩 9/10 时就显示不足。源码原绝对阈值至少为 10，导致总额只有 10 的 bucket 始终警告。新增两项回归先失败，修复为绝对/比例阈值最多不超过总额一半；大 bucket 保留现有阈值，单请求 bucket 仅空额度告警。
2. 1.5 倍字体时额度提示标题及重置时间被截断。新增 320dp / 1.5 字体的真实 TextLayoutResult 溢出检查先失败；源码移除状态提示的单行限制，允许换行。修复经主机回归，尚未安装到此模拟器复查。
3. 设置切换的 gfxinfo 记录 34 帧中 34 帧超预算、P50 93ms / P90 300ms。随后实际出现 **System UI isn't responding**，事件缓冲区记录 `com.android.systemui` 的导航栏输入超时（设备时间 04:38:26）。这表示当前运行环境本身也有异常，不能把该数据当作应用独立性能结论，亦不能声称性能通过。已保存系统提示截图与 am_anr 事件，并尝试保留数据重启手机模拟器恢复环境。

保留数据的系统重启后 ADB 曾离线，重连后虽完成开机，截图服务仍卡住。随后只停止并冷启动上述手机 AVD，不加载或保存快照、不清除数据、不安装包。开机完成后 ADB、截图和 UIAutomator 恢复正常；已确认原 1.5 字体设置仍保留。硬件加速检查显示 WHPX 可用。

恢复后实际从主页进入未登录个人页、GitHub 登录页，再进入生产 GitLab 账号页。GitLab 的 OAuth / PAT 输入及向下滚动到 PAT 按钮已检查并截图，空凭据按钮禁用；没有启动授权、输入凭据或保存账号。该旧包底部说明尚仅支持 GitLab 账号，进一步证明不能以其代替当前 GitLab 功能源码验收。

冷启动后重新录制设置进入/退出，保留 `settings-cold-boot.mp4` 及抽帧图。对应 gfxinfo 记录 142 帧、20 帧超预算（14.08%），P50 20ms / P90 26ms / P95 34ms；仍是旧 debug 包、模拟器、录屏中的局部观察，不能作为最新版应用的独立基准或性能通过依据。该次旧包检查仍有丢帧，最新构建的复测待完成。
