# Release 确认与 Markdown 图片复查

本轮修复属于客户端持续验收，**不代表稳定版验收通过**。完整发布要求仍见 [客户端验收矩阵](CLIENT_ACCEPTANCE.md)。最新命令结果与源码、模拟器安装包及截图哈希见 [机器可读记录](verification-2026-10-24.json)。

## 修复范围

- Release 列表的未确认结果提示加入滚动列表，避免多项提示挤占整屏。提示显示操作类型和目标 ID，按钮可换行。
- 编辑页显示未确认结果和记录读取失败；本地操作记录未就绪时禁用保存和其他写入口。
- 详情页提供查看最新状态和本地确认入口；本地确认只分派 Acknowledge，不删除、上传或再次发布。
- 删除发布、删除附件的重复确认在同一个弹窗内分两步核对。取消、切号、权限变化或操作记录失效会清除待确认状态，编辑内容变化也使保存确认失效。
- 文件选择目标不跨重建恢复；读取文件名、类型和大小改在 IO 线程执行，读取失败显示可理解的提示。异步读取完成后再次核对账号、仓库和权限。取消上传重复确认会释放待提交动作引用。
- Markdown 图片的加载阶段显示说明；失败显示明确的重试按钮，用户点击才重新请求。拒绝的图片地址显示不可用原因类别，不发起请求；成功继续使用解码后的尺寸与原有相对路径、SVG、HTML 图片支持。

## 回归范围和证据边界

新增 7 项 Robolectric 原生 Compose Release 测试，覆盖详情提示的本地确认、记录失败禁写、提示与列表一起滚动、重复删除/取消、撤销权限、附件重复删除及编辑后确认失效。初始回归有实际功能失败；列表查询最初无法查找尚未组合的条目，改为通过 LazyGrid 的滚动语义查找后验证。

新增 3 项原生 Markdown 图片测试，先复现加载、错误和不可用提示缺失，再验证加载结束绘出已知位图像素、失败仅在点击后重试，以及禁止的 URI 不调用加载器。使用可控 Coil 拦截器，不依赖外网。

本轮测试没有模拟真实 Android 系统杀进程。此前 Release ViewModel 重建和底层记录持久化测试也不能证明真实 OS 进程死亡路径。文件选择器的系统提供程序、真实私有仓库、真实发布写入和全部账号导航仍需独立验收。

此前运行 connectedDebugAndroidTest 的报告实际为 **0 项测试**，不得视为设备自动化验收通过。本轮 ADB 截图属于人工设备观察；示例页与真实未登录页面分别标记。

## Markdown 模拟器观察纠正

上一轮在外网图片尚未返回时截图，图片区域为空。本轮重新打开同一示例并等待后，相对 PNG、SVG 徽章及 HTML 图片均正常显示，因此没有证据支持“所有图片均无法解析”的结论。本轮补的是等待反馈和错误恢复。网络示例不证明所有 README 语法、私有图片权限或长文性能均已通过。
