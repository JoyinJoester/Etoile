## 本轮已确认问题

- APK 下载后完整性检查、包解析和大目录的已安装版本查询回到主线程；下载取消未绑定网络调用，失败会留下半成品。修复后需保留下载取消、截断、哈希不匹配和路径验证测试证据。
- GitHub 部分仓库子页面切换账号后仍保留旧权限或私有内容；需同时处理 UI 确认、ViewModel 和迟到响应。
- Stars 使用全局标签图并保留旧选择、筛选和编辑状态；需分账号存储并定义旧数据迁移。
- 通知的刷新、逐条操作和全部已读之间可能相互覆盖；需证明并发失败回滚不会撤销较新的成功结果。
- README 的应用 ID、工具链、GitLab 支持范围和部分写操作说明与当前源码不一致。
- Release 依赖坐标的 OSV 查询发现 jsoup 1.18.3 对应两项公开公告（GHSA-65r4-943x-97jj、GHSA-pmhh-3w7g-xqp8）。已升级至 1.23.2，需验证实际解析版本与 Markdown 回归；公告命中不等同于应用内可利用性结论。
- Release 曾与 Debug 共用 OAuth Client Secret，现已固定为空；源码验证与 Release pre-build 均检查，模拟注入非空 Secret 被拒绝。公开发行配置检查目前仅因正式签名未配置而失败；真实授权、签名及升级仍需验收。未读取或输出 Secret / 私钥。
- Discussion 详情原先依赖组合状态、动态账号仓库回调；评论行回收可取消修改，删除确认可恢复，答案变更未二次确认。现接入持续账号观察、绑定令牌、持久草稿与未确认结果，修改禁止自动重放；评论/讨论编辑均为整页表单，补齐答案确认及顶层/楼中楼重复发送确认。主机与请求层证据见 [Discussions 详情验证](DISCUSSION_INTERACTIONS_2026-10-22.md)，完整应用导航、进程死亡和真实写入仍待验收。
- CreatePR 的保存状态会在覆盖页切号、返回后恢复旧编辑器打开标志；现只保存账号所属的文字，重进或新宿主恢复需手动打开编辑器。新增 7 项主机生产导航回归，覆盖保留页切号、确认失效、暂停时不跳转、成功只消费一次、旧非合作成功，以及 Parcel 保存 Bundle 后的新宿主/新 ViewModelStore 恢复。范围和限制见 [会话导航验证](CONVERSATION_NAVIGATION_2026-10-22.md)。

## 证据规则

GitHub 多个资源接口曾沿用默认 OkHttp 策略，`503 + Retry-After: 0` 会自动重放写操作。13 类代表操作的修复前回归均失败；现通过一次性请求体、禁止自动重试/重定向及可取消 Call 修复。新增 52 项矩阵和 3 项辅助测试，扩展定向 261 项及完整套件均通过。具体覆盖与限制见 [GitHub 写入传输验证](GITHUB_MUTATION_TRANSPORT_2026-10-22.md)；此结果不能证明全部写操作已完成账号绑定、不确定结果处理或真实远端验收。

本轮详见 [验证记录](VERIFICATION_2026-10-22.md)、[机器可读结果](verification-2026-10-22.json) 和 [发布流程](RELEASE_PROCESS.md)。浏览器 OAuth pending-store、GitLab 加密存储和 F-Droid 筛选已移至后台；真实启动、超大目录和帧耗时尚未测量，不能归为流畅性验收通过。

历史报告只证明对应历史状态。每轮变更后记录实际执行的命令、日志、测试范围和限制；定向测试结果不冒充全量结果。Canvas 是设计工具，Robolectric 是主机原生组件验证，两者均不证明真机帧率、真实认证或正式安装包可用。

真实账号测试不得读取现有私密凭据文件。需要用户在浏览器亲自授权；写入测试须先明确账号与可修改的测试项目。正式签名、发布、安装与远端写入按用户授权执行。
